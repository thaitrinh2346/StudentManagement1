## Mô tả Project
Ứng dụng quản lý sinh viên đơn giản được phát triển trên nền tảng .NET 8 Windows Forms, ứng dụng quy trình quản lý mã nguồn theo mô hình Feature Branch Workflow của Git/GitHub.

## Các Control đã sử dụng
* **Form / GroupBox / Panel:** Định hình và phân chia khu vực giao diện.
* **Label / TextBox:** Nhập dữ liệu chuỗi (MSSV, Họ tên, Email, SĐT).
* **ComboBox:** Chọn Lớp học / Khoa.
* **DateTimePicker:** Chọn ngày tháng năm sinh.
* **Button:** Hệ thống các nút thao tác (Thêm, Sửa, Xóa, Làm mới, Thoát).
* **DataGridView:** Bảng hiển thị danh sách sinh viên trực quan.
